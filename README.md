# 🎓 Face Recognition Student Attendance System

An AI-powered Student Attendance System that uses Face Recognition to automatically identify students and mark attendance in real time.

## 📌 Features

- Secure Login System
- Student Management
- Face Detection using OpenCV
- Face Recognition using LBPH Algorithm
- Automatic Attendance Marking
- Attendance Records
- MySQL Database Integration
- Tkinter GUI

## 🛠️ Technologies Used

- Python
- OpenCV
- Tkinter
- MySQL
- Pillow
- NumPy

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Sudeepdhami7/Face-Recognition-Student-Attendance-System.git
```

### 2. Go to the Project Folder

```bash
cd Face-Recognition-Student-Attendance-System
```

### 3. Install Required Libraries

```bash
pip install opencv-contrib-python opencv-python numpy pillow mysql-connector-python
```

### 4. Run the Project

```bash
python main.py
```
